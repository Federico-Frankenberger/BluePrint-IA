# Requerimientos funcionales

- **RF-01:** El sistema deberá permitir a un vendedor crear un pedido especificando productos y cantidades. _(fuente: proceso: Crear pedido)_
- **RF-02:** El sistema deberá permitir modificar un pedido existente. _(fuente: proceso: Modificar pedido)_
- **RF-03:** El sistema deberá restringir la modificación de un pedido únicamente al vendedor que lo creó. _(fuente: RN-01)_
- **RF-04:** El sistema deberá impedir la modificación de un pedido una vez que fue aprobado. _(fuente: RN-02)_
- **RF-05:** El sistema deberá permitir a un administrador aprobar un pedido pendiente. _(fuente: proceso: Aprobar pedido)_
- **RF-06:** El sistema deberá permitir a administración consultar el listado de pedidos. _(fuente: proceso: Consultar pedidos)_
